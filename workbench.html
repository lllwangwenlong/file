📊 结构小结
维度内容
场景数8 个（S1~S8），覆盖正常路径 + 边缘路径 + 降级
组件数3 个前端组件（TodoView / TodoForm / TodoList）+ 2 个基础设施（Store + API）
后端1 个 Express 服务，内存数组存储，REST 接口 GET/POST /todos
路由1 条 /todos → TodoView（懒加载），history 模式
交互极简：聚焦输入 → 填写 → 回车/点击 → 即时追加。无编辑、删除、标记完成。
动画仅 CSS transition（focus 0.2s、hover 0.2s），无额外入场/列表动画，Nprogress 已由路由层处理
色彩蓝 #409eff 主操作、灰 #333~#bbb 层级文本、红 #e74c3c 错误
响应式最大 720px 居中，移动端撑满，无断点拆分（MVP）
约束最小闭环仅创建、内存存储、history 模式、无鉴权、无 i18n、无 a11y
